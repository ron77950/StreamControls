# Twitch setup

Stream Controls uses Twitch's device authorization flow for a public client. The client ID in `app/build.gradle.kts` is public; it is not a client secret. Do not embed a Twitch client secret in the app. If building a fork using a different Twitch application, register a public application in the [Twitch Developer Console](https://dev.twitch.tv/console/apps) and replace the client ID. Follow Twitch's current registration requirements, including any account security requirements.

In Accounts, select **Connect Twitch**, open the displayed Twitch activation page, enter the displayed code if requested, and authorize the `channel:manage:broadcast` permission. Twitch controls which account is signed in in the browser. Stream Controls verifies and saves that account automatically; close the browser tab to see the connected channel. The scope permits managing broadcast settings beyond just the title. To connect another account, repeat the flow while signed in to that account in the browser.

When supported, Stream Controls opens Twitch in a browser Custom Tab using a bound session and asks the browser to keep redirects in the tab. It prefers Chrome when available and otherwise uses another compatible browser. If a session is unavailable, it opens a browser instead. Browser behavior can vary, and Twitch does not redirect back to the app in this device-code flow. You may need to return manually after authorizing.

If authorization completes while Stream Controls is covered, the app can show a **Twitch connected** notification. Tap it to return to Stream Controls. The **Accounts connected** switch under Settings → Notifications controls this alert. On Android 13 and later, notifications require permission; connecting still works if permission is declined or notifications are disabled. Notifications depend on the connection process remaining active and cannot be guaranteed if Android stops the app.

The app encrypts refresh tokens on the device, keeps access tokens in memory, and validates Twitch sessions on restoration and periodically while the app is foregrounded. Public-client refresh tokens are single use; if a refresh cannot be completed safely, reconnect the channel. Disconnect attempts token revocation as well as local removal. You can also remove the application's access through Twitch account settings.

The app lists live Twitch streams and can change their titles. Stop a Twitch stream using your streaming software. Twitch sign-in, persistent restoration, stream discovery and title changes have not yet been verified with a real account. See Twitch's [device authorization documentation](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/) and [token validation requirements](https://dev.twitch.tv/docs/authentication/validate-tokens/).
